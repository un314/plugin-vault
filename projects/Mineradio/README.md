# Mineradio

- 上游：https://github.com/XxHuberrr/Mineradio
- 分类：生活与科技 ｜ 类型：node
- 存放：常驻（D 盘）
- 用途：沉浸式音乐播放器（Electron + Web）
- 运行：npm install && npm start（或双击 start-mineradio.bat）
- 按需拉取：`powershell -ExecutionPolicy Bypass -File scripts\fetch-project.ps1 -Name Mineradio`（默认临时目录，跑完 -Clean）
- 要转常驻：同上加 `-Keep`，落到 `D:\github专用仓库\plugins\mineradio`
- 详细说明：[docs/Mineradio.md](../../docs/Mineradio.md)
- 返回总索引：[PROJECTS.md](../../PROJECTS.md)

---

存放规则：基础能力、高频或大用量才常驻 D 盘；其余按需拉取，用完清理。
