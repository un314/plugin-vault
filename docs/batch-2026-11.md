## 四、跑起来的最小步骤

```powershell
# 本地模型 + 网页工作台（多 Agent 工作流底座）
ollama run qwen3
docker run -d -p 3000:8080 --add-host=host.docker.internal:host-gateway `
  -v open-webui:/app/backend/data --name open-webui open-webui/open-webui:main

# Dify（工作流 / 知识库）
git clone https://github.com/langgenius/dify
cd dify\docker; copy .env.example .env; docker compose up -d

# 抖音下载
git clone https://github.com/jiji262/douyin-downloader
cd douyin-downloader; pip install -r requirements.txt; python run.py
```

本机无 Docker，涉及容器化的项目只能先登记，等装 Docker 或换机器再起。
