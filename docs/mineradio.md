# Mineradio — 沉浸式音乐播放器

**上游**：https://github.com/XxHuberrr/Mineradio
**备份**：https://github.com/un314/Mineradio-paused（fork，含完整历史）
**本地**：`D:\github专用仓库\plugins\mineradio`
**类型**：Node / Electron
**版本**：`649c787`

## 用途

以电影镜头、粒子视觉和歌词舞台为核心的沉浸式音乐播放器。

## 依赖

Node.js 20+、Windows。

## 安装

```powershell
cd "D:\github专用仓库\plugins\mineradio"
npm install
```

## 运行 / 使用

```powershell
npm start        # 或双击 start-mineradio.bat
```

## 验证

```powershell
Test-Path "D:\github专用仓库\plugins\mineradio\node_modules"
```

上游已改名 Mineradio-paused（暂停维护），功能可用但不再更新。
